- Adapted from [mattpocock/skills](https://github.com/mattpocock/skills).
- Takes an existing `./specs/<feature>.md` and thinks it further — a half-implementation on paper.
- Shapes the interfaces each module will actually expose, with decision-rich code snippets.
- Estimates per module: line-count delta, complexity, abstractions touched — to surface risk early.
- Slices the work vertically into tracer-bullet slices, expand–contract for wide refactors.
- Everything lands in the same spec under a `## Refinement` section — no separate plan artifact.
