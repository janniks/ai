- A structured loop for hard bugs and performance regressions, not quick typos.
- Reproduces first, then isolates the smallest failing case.
- Confirms the root cause with evidence before proposing a fix.
- Fires on "diagnose" / "debug this", or reports of something broken, throwing, failing, or slow.
