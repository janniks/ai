- Reviews changes since a fixed point (commit, branch, tag, or merge-base).
- **Standards axis:** does the code follow `AGENTS.md`, `CONVENTIONS.md`, and a Fowler smell baseline?
- **Spec axis:** does the code do what the originating spec asked for?
- Runs both axes in parallel sub-agents and reports them side by side — no cross-axis reranking.
