> **Outside the normal flow** — mainly for users with signing keys, where the agent can't run the commit itself. Not referenced in the AGENTS.md template.

- Stages **only** the files the agent changed — never `git add -A` — safe in shared repos and worktrees.
- Writes a commit message matching the repo's history style (prefix, scope, capitalization).
- Leaves the actual `git commit --no-edit` to you.
