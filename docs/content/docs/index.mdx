## Skills

### Install

Install all skills with the following command:

```bash
npx skills add janniks/ai
```

---

Or install single skills:

**create-spec:** Creates a spec through user interview, codebase exploration, and module design, then saves to `./specs/<feature>.md`.

```bash
npx skills add janniks/ai/create-spec
```

**refine-spec:** Deepens an existing spec toward a half-implementation — interface shapes, code examples, size estimates, and vertical slices — under a `## Refinement` section.

```bash
npx skills add janniks/ai/refine-spec
```
