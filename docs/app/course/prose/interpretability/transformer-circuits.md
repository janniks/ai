The mathematical framework reads an attention head as two separable circuits: the QK circuit $W_Q^\top W_K${tip:the query weights combined with the key weights into one matrix; it alone determines which positions the head attends to}, which decides where to attend, and the OV circuit $W_O W_V${tip:the output weights combined with the value weights into one matrix; it alone determines what information is copied once attention lands}, which decides what is moved when attention lands. Because everything is written into a shared running record called the residual stream, heads in later layers can read what earlier heads wrote, and combinations of heads implement algorithms.

The induction head is the proof of concept: a two-head circuit that finds the previous occurrence of the current token and copies what followed it, completing the pattern A B then later A, so predict B. These heads appear abruptly during training, coincide with a visible bump in the loss curve, and account for a substantial part of in-context learning, a mechanistic explanation of a capability that otherwise looks emergent.
