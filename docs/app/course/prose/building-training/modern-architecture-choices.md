The deltas between GPT-2 and a current open model are few and learnable. RMSNorm replaces layer normalization, rescaling each token's vector by its average size without first centering it. SwiGLU replaces the plain feed-forward layer with a gated form, in which one transformed copy of the input switches another on and off elementwise. RoPE replaces learned absolute positions. Grouped-query attention shares each key-value head across several query heads to shrink the KV cache.

Each change is small; together they are roughly the difference between 2019 and now at a given scale. The useful arithmetic to carry forward: a model with $N$ parameters, meaning $N$ learned numbers, trained on $D$ tokens costs about $6ND${tip:six times the parameter count times the token count gives the total number of multiply-adds of training, a remarkably reliable estimate} arithmetic operations. That estimate is the bridge to scaling laws.
