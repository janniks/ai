One block of the architecture, in the form used by modern models:

$$x \leftarrow x + \mathrm{MHA}(\mathrm{LN}(x)), \qquad x \leftarrow x + \mathrm{FFN}(\mathrm{LN}(x)),$${tip:Read each arrow as becomes, so x becomes x plus the multi-head attention of the normalized x, and then x becomes x plus the feed-forward network of the normalized x. In plain words, normalize the vector, run attention over it, and add the result back onto the original; then normalize again, run the small feed-forward network, and add that back on too. The adding back is the key habit, because each block only nudges a running stream instead of replacing it, which keeps very deep stacks trainable.}

where $x$ is a word's running vector, $\mathrm{MHA}${tip:Read this as M H A, short for multi-head attention. It is the operation where every word compares itself with every other word and pulls in information from the relevant ones, run several times in parallel with different learned criteria. It is the only part of the block where words exchange information with each other.} is the multi-head attention of the previous concept, $\mathrm{FFN}${tip:Read this as F F N, short for feed-forward network. It is a small two-layer neural network applied to each word's vector separately, with no communication between positions. It holds most of the block's adjustable numbers and does the heavy reworking of each word's representation.} is a small two-layer network applied to each position alone, and $\mathrm{LN}${tip:Read this as L N, short for layer normalization. It rescales a vector so its numbers always have a standard average size, no matter what came before. This keeps the values from drifting too large or too small as they pass through many layers, which keeps training stable.} (layer normalization) rescales a vector to a standard size so training stays stable. The additions are the crucial habit: each block computes a small update to a persistent stream rather than replacing it, so learning signals flow cleanly however deep the stack.

Attention is the only place where positions exchange information; the feed-forward network, which holds about two thirds of the parameters, transforms each position alone. A GPT is a few dozen of these blocks between a lookup table that turns words into vectors and a final layer that turns vectors back into word probabilities.
