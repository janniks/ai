Formally: each word's vector $x$ is multiplied by three learned weight matrices to give a query $q$ (what this word is looking for), a key $k$ (what this word offers), and a value $v$ (what this word will pass along if chosen). Collect them over all positions into the matrices $Q$, $K$, $V$, and attention is

$$\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right) V.$${tip:Read it as attention of Q, K, V equals the softmax of Q times K transposed, divided by the square root of d k, all multiplied by V. In plain words, compare every word's query with every word's key to get relevance scores, shrink those scores by the square root of the vector length so they stay in a workable range, turn each row of scores into percentages that sum to one, then blend the value vectors using those percentages. This one line is the whole mechanism that lets each word gather information from the words most relevant to it.}

Reading it from the inside out: $QK^\top${tip:Read this as Q times K transposed. It multiplies the table of queries by the flipped table of keys, which works out to comparing every word's query with every word's key in one shot. The result is a grid of numbers where each entry says how relevant one position is to another.} scores how relevant each position is to each other position; the softmax turns each row of scores into positive weights summing to one; each position's output is then a weighted blend of the values. Dividing by $\sqrt{d_k}${tip:Read this as the square root of d k, where d k is just the length of each query and key vector, meaning how many numbers it contains. Longer vectors naturally produce bigger scores when compared, so dividing by this amount cancels that growth. Without it the softmax would saturate and the attention weights would stop being sensitive to differences.} (the square root of the vector length) keeps the scores in a range where the softmax stays sensitive.

Multi-head attention runs several such operations in parallel with separate weights, letting different heads attend by different criteria. In a GPT, a causal mask blocks every position from seeing anything to its right, which is what makes next-word training honest.
