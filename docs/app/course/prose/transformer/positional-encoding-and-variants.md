Attention is permutation-invariant: shuffle the tokens and the scores shuffle with them. Order must be injected. The original paper added fixed sinusoids to the embeddings, $\mathrm{PE}_{(t, 2i)} = \sin(t / 10000^{2i/d})$; most current models instead use rotary embeddings, which rotate each query-key pair by an angle proportional to its position, so the dot product $q_t^\top k_s$ depends only on the relative offset $t - s$. Relative position is what language actually uses, and RoPE encodes it without adding anything to the residual stream.

The block structure itself has been remarkably stable since 2017. What has changed are these margins: positional schemes, normalization placement, attention variants for efficiency. The architecture chapters ahead are largely a tour of such refinements.
