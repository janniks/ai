Attention treats its input as a bag: shuffle the words and the relevance scores shuffle with them, so word order must be injected separately. The original paper added fixed wave patterns to each word's vector, a different mix of frequencies for each position. Most current models instead use rotary embeddings (RoPE), which rotate each query and key by an angle that grows with position, so the comparison between two words depends only on how far apart they are, written $t - s${tip:the distance between position t and position s in the text}. Relative distance is what language actually uses.

The block structure itself has been remarkably stable since 2017. What has changed are these margins: positional schemes, normalization placement, attention variants for efficiency. The architecture chapters ahead are largely a tour of such refinements.
