A vector is a list of numbers, a point or an arrow in space; a matrix is a rectangular grid of numbers. The single operation to internalize is multiplying a matrix by a vector: the matrix $W$ takes in a vector and puts out a new one, and the only moves it can make are rotations, stretches, shears, and flattenings. Every layer of every model in this curriculum is such a map followed by a simple bending operation.

Two consequences matter constantly.
