Everything that follows is built from a small mathematical toolkit: vectors and matrices, lists and grids of numbers, to represent data and transformations; derivatives to improve them; and probability to say what a model believes. A language model is, in the end, a function $f_\theta${tip:a function f whose behavior depends on its parameters theta; same input, different theta, different output}: a machine that takes a sequence of numbers standing for words and returns, for each possible next word, how likely it is. Its adjustable inner numbers, called parameters and written collectively as $\theta$ (the Greek letter theta), are found by calculus.

You do not need the full undergraduate canon. You need to see a grid of numbers multiplying a list of numbers as a geometric transformation, to know that a gradient is the direction in which a quantity grows fastest, and to be comfortable with averages and with probabilities that depend on context. The resources here build exactly that, mostly visually.

This chapter is optional in the strict sense: skip anything you already own, and return when a later derivation feels opaque. The rest of the curriculum assumes these tools without ceremony.
