Everything that follows is built from a small mathematical toolkit: vectors and matrices, lists and grids of numbers, to represent data and transformations; derivatives to improve them; and probability to say what a model believes. A language model is, in the end, a function $f_\theta${tip:Read this as a function named f with a small theta attached below it. The theta stands for all the adjustable numbers inside the function, so the subscript is a reminder that the function's behavior depends on them. Feed it the same input with different theta values and you get different outputs, which is why training, which adjusts theta, changes what the model does.}: a machine that takes a sequence of numbers standing for words and returns, for each possible next word, how likely it is. Its adjustable inner numbers, called parameters and written collectively as $\theta$ (the Greek letter theta), are found by calculus.

You do not need the full undergraduate canon. You need to see a grid of numbers multiplying a list of numbers as a geometric transformation, to know that a gradient is the direction in which a quantity grows fastest, and to be comfortable with averages and with probabilities that depend on context. The resources here build exactly that, mostly visually.
