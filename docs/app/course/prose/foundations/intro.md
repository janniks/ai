Everything that follows is built from a small mathematical toolkit: vectors and matrices to represent data and transformations, derivatives to improve them, and probability to say what a model believes. A language model is, in the end, a function $f_\theta$ from sequences of integers to probability distributions, and $\theta$ is found by calculus.

You do not need the full undergraduate canon. You need to read $y = Wx + b$ and see a geometric transformation, to know what $\nabla_\theta \mathcal{L}$ points at, and to be comfortable with expectations and conditional distributions. The resources here build exactly that, mostly visually.

This chapter is optional in the strict sense: skip anything you already own, and return when a later derivation feels opaque. The rest of the curriculum assumes these tools without ceremony.
