A geometric reading of the same machinery: think of the data as a crumpled sheet in a vast space. Each layer bends and folds that sheet, and depth composes folds. Categories that are hopelessly tangled in the raw input become cleanly separable after enough folds, so the final layer only needs to draw a straight boundary between them. Depth is efficient because a sequence of folds can express, with few parameters, shapes that a single wide layer would need astronomically many neurons to imitate.

This picture also previews representation learning. The numbers flowing between layers are not bookkeeping; they are learned coordinates in which the task is easy. Embeddings, attention, and the features of the interpretability chapter are all statements about these intermediate spaces.
