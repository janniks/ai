A single neuron computes $\sigma(w^\top x + b)${tip:multiply each input number by its own weight, add the results together, add the bias, then pass the total through the squashing function}. Here $x$ is the list of input numbers, $w$ is a matching list of learned weights saying how much each input matters, $b$ is a learned offset called the bias, and $\sigma$ (sigma) is a simple nonlinear function applied at the end, such as replacing anything negative with zero. A layer runs many neurons side by side on the same input, and a network stacks layers.

The nonlinearity is not decoration. Chaining purely linear steps gives just another linear step, so without $\sigma$ the deepest network collapses into one. With it, a network can approximate essentially any input-to-output relationship, given enough neurons. That guarantee says good weights exist; it says nothing about finding them. That is the next concept's problem.
