Write the loss as $\mathcal{L}(\theta)${tip:the average error the network with parameters theta makes across the training examples}: one number, depending on the parameters $\theta$, that says how wrong the network currently is. The gradient, written $\nabla_\theta \mathcal{L}${tip:for every parameter, how much a tiny increase in it would raise or lower the error}, lists for each parameter how the error responds to nudging it. Training repeatedly steps every parameter the other way: $\theta \leftarrow \theta - \eta \nabla_\theta \mathcal{L}${tip:new parameters equal old parameters minus a small step in the error-reducing direction; eta is the step size}, where the small number $\eta$ (eta) is called the learning rate.

In practice the gradient is estimated on a small random batch of examples rather than the whole dataset. The estimate is noisy, but the noise is tolerated, and arguably helpful, in exchange for many more updates per unit of compute. Adam, the default optimizer for the models ahead, smooths the steps over time and gives each parameter its own step size, so all of them move at comparable speeds.
