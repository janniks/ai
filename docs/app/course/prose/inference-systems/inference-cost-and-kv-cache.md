During generation, the keys and values that attention computed for all previous tokens are stored so each new token is processed once, not the whole prefix again. The cache is large: it holds a few numbers per layer, per attention head, per token of context, and at long contexts it, not the model's weights, dominates memory. This is why grouped-query attention and DeepSeek's latent attention exist; both are compressions of exactly this object.

The other fact to internalize: producing one token requires reading every one of the model's stored numbers from memory once, while doing only about two arithmetic operations per number read. Modern GPUs can do hundreds of operations in the time it takes to load one byte, so generating for a single user leaves the compute units mostly idle. Batching, speculative decoding, and the kernels of the next concept are all ways to buy arithmetic with memory traffic already spent.
