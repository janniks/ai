Byte-pair encoding starts from raw bytes and repeatedly merges the most frequent adjacent pair into a new token, until the vocabulary reaches a chosen size, typically $50{,}000$ to $200{,}000$. Common words become single tokens; rare strings shatter into fragments. The model never sees characters, only these learned chunks.

This explains a family of otherwise baffling behaviors. Arithmetic is hard partly because digits group inconsistently; spelling questions are hard because the model cannot see inside a token; a string that appears in the tokenizer's training data but rarely in the model's, a glitch token, has an essentially untrained embedding. When a model fails strangely, suspect the tokenizer first.
