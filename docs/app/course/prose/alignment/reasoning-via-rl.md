When the reward is verifiable, a math answer checked exactly, code run against tests, the proxy problem of RLHF largely disappears, and RL can be applied with force. DeepSeek-R1's result is that long chain-of-thought reasoning, including self-checking and backtracking, emerges from pure RL on such rewards, without being demonstrated. GRPO, the algorithm used, drops the learned value function: it samples a group of responses per prompt and uses each one's advantage relative to the group mean as the signal.

This trades training compute for inference compute. The model learns to spend more tokens thinking when the problem warrants it, a second scaling axis alongside the pretraining laws of chapter four. The process-supervision result reinforces the theme from the other side: rewarding each correct step beats rewarding only correct final answers.
