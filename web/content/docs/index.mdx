A personal collection of [Agent Skills](https://agentskills.io/) and the agentic coding flow that uses them.

## Install

Whole collection:

```bash
npx skills add janniks/janniks-ai
```

Single skill:

```bash
npx skills add janniks/janniks-ai/create-spec
npx skills add janniks/janniks-ai/create-plan
```
