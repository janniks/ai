# Seeing Theory (Brown University)

Interactive, D3.js-driven visual intro to probability and statistics — the
3Blue1Brown of stats. Free PDF textbook draft included. Great first pass
before a rigorous course (Stat 110).

## Chapters

1. **Basic Probability** — chance events, expectation, variance
2. **Compound Probability** — set theory, counting, conditional probability
3. **Probability Distributions** — random variables, discrete & continuous,
   central limit theorem
4. **Frequentist Inference** — point estimation, interval estimation, the bootstrap
5. **Bayesian Inference** — Bayes' theorem, likelihood, prior → posterior
6. **Regression Analysis** — ordinary least squares, correlation, ANOVA
