# Stanford CS231n: Deep Learning for Computer Vision

The legendary course notes — the best written intro to neural nets,
backprop, optimization, and CNNs anywhere. Even if you don't care about
vision, Modules 0–1 of these notes are the clearest backprop/optimization
explanation on the internet (CS224n itself assigns them).
