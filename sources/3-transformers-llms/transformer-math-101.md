# Transformer Math 101
Training large transformer models needs careful memory planning for model weights, activations, gradients, and optimizer states. Techniques like mixed precision, recomputation, and sharded optimizers help reduce memory use. Distributed training uses parallelism and memory sharding to fit huge models on GPU clusters efficiently.
