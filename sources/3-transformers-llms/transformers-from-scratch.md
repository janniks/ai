# Transformers from scratch
Transformers are advanced machine learning models that use a key operation called self-attention to process sequences of data. Self-attention allows the model to weigh the importance of different input elements when generating output, enabling it to capture relationships across the entire sequence. By combining self-attention with other techniques, transformers can efficiently learn complex patterns without relying on traditional recurrent networks.
