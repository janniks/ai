# Stanford CS224N: NLP with Deep Learning

The definitive academic LLM course — word vectors → RNNs → transformers →
pretraining → post-training (RLHF/DPO) → agents → interpretability. Each
lecture is anchored to the seminal papers. The single best structured path
for Module 3, and it threads into Modules 5 (RL) and 6 (interpretability).

- Public lecture videos: https://www.youtube.com/playlist?list=PLoROMvodv4rOaMFbaqxPDoLWjDaRAdP9D
- Course site (slides, notes, assignments): https://web.stanford.edu/class/cs224n/

## Lecture arc (Winter 2026) with key papers

1. **History of NLP**
2. **Word Vectors** — [Word2Vec](http://arxiv.org/pdf/1301.3781.pdf), [GloVe](http://nlp.stanford.edu/pubs/glove.pdf)
3. **Backprop & Neural Net Basics** — assigns CS231n notes; matrix calculus
4. **Language Models & RNNs** — vanishing gradients, [Attention Is All You Need](https://arxiv.org/abs/1706.03762)
5. **Transformers** — [Illustrated Transformer](https://jalammar.github.io/illustrated-transformer/), layer norm
6. Final project tips ([DL book methodology](https://www.deeplearningbook.org/contents/guidelines.html))
7. **Pretraining** — [BERT](https://arxiv.org/pdf/1810.04805.pdf), [Llama 3](https://arxiv.org/abs/2407.21783)
8. **Post-training** — RLHF, SFT, [DPO](https://arxiv.org/abs/2305.18290), [InstructGPT](https://openai.com/research/instruction-following)
9. **Efficient Adaptation** — [GPT-3 few-shot](https://arxiv.org/abs/2005.14165), [LoRA](https://arxiv.org/abs/2106.09685)
10. **Agents, Tool Use, RAG** — [ReAct](https://arxiv.org/abs/2210.03629), [RAG](https://arxiv.org/abs/2005.11401), [Toolformer](https://arxiv.org/abs/2302.04761)
11. **Benchmarking & Evaluation** — [MMLU](https://arxiv.org/abs/2009.03300), [HELM](https://arxiv.org/abs/2211.09110)
12–13. **Reasoning** — [Chain-of-Thought](https://arxiv.org/abs/2201.11903), [DeepSeek-R1](https://arxiv.org/abs/2501.12948), [test-time compute](https://arxiv.org/abs/2408.03314), [RoPE](https://arxiv.org/abs/2104.09864)
14. **Tokenization & Multilinguality** — [BPE/subwords](https://arxiv.org/pdf/1508.07909)
15. **Interpretability** (guest: Been Kim)
16. **Social & Broader Impacts / Risks**
17. **Multimodality** (guest: Luke Zettlemoyer)
18. **LoRA Without Regret** (guest: John Schulman)
19. **Open Questions in NLP 2026**

> Reference text throughout: Jurafsky & Martin, *Speech and Language
> Processing* — https://web.stanford.edu/~jurafsky/slp3/
