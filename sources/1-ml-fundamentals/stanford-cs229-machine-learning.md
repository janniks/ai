# Stanford CS229: Machine Learning

The rigorous, math-heavy ML course (the depth pass after Andrew Ng's
Coursera specialization). Statistical pattern recognition from first
principles.

## Covers

- Supervised learning — generative & parametric/non-parametric approaches,
  neural networks
- Unsupervised learning — clustering, dimensionality reduction
- Learning theory — bias/variance, VC dimension, generalization
- Reinforcement learning
- Applications: robotics, data mining, autonomous navigation, bioinformatics,
  speech, web/text data

**Prerequisites:** Python/NumPy, probability (CS109), calculus & linear
algebra. This is where Module 0 math pays off.
