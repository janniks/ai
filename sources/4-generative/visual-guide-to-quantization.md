# A Visual Guide to Quantization
Quantization is a technique used to reduce the number of bits needed to represent the parameters of large language models while maintaining their accuracy. It involves methods like post-training quantization and quantization-aware training, which adjust the model during or after training. The goal is to create more efficient models that use less memory and computational power.
