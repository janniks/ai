# janniks-ai

Install the whole collection:

```bash
npx skills add janniks/ai
```

Or a single skill:

```bash
npx skills add janniks/ai/create-spec
npx skills add janniks/ai/create-plan
```

Docs: [`web/`](./web) (Fumadocs).
